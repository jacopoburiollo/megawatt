# Megawatt

Megawatt finances utility-scale solar and battery storage projects, held through dedicated vehicles, with energy revenue returned to investors and asset performance published onchain.

## Source code

The source code is proprietary and not open source. Code walkthroughs and verified deployments are available to grant reviewers, auditors and partners on request.
